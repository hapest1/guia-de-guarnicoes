# Alves & Ivaniski Advogados Associados — site

Site estático (HTML/CSS/JS puro, sem build), hospedado provisoriamente em `/alves-ivaniski`.
Está com `noindex` e fora do sitemap do guia.

- `dados.js` — **edite aqui**: nome, OAB, cidade, textos, áreas de atuação e contatos.
- `index.html` — estrutura e textos fixos.
- `app.js` — preenche a página a partir de `dados.js`.
- `style.css` — visual.
