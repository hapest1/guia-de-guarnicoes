# OBA Food Park — site

Site estático (HTML/CSS/JS puro, sem build) do OBA Food Park, Uruguaiana/RS.

- `dados.js` — **edite aqui**: lojas, horários, WhatsApp, endereço, parceiros.
- `index.html` — estrutura e textos em português.
- `app.js` — status "aberto agora", filtros, roleta, formulários → WhatsApp, tradução PT/ES.
- `style.css` — visual.

Para adicionar uma loja, copie um bloco dentro de `lojas` em `dados.js` (nome, emoji, cor, categorias, Instagram e textos PT/ES). A roleta e a grade se atualizam sozinhas.
